
# Customer Churn Analysis

## Project Overview
This project focuses on analysing customer behaviour,
identifying churn patterns, and understanding factors
associated with customer retention.

## Objectives
- Explore customer data.
- Clean and preprocess the dataset.
- Perform exploratory data analysis.
- Analyse customer segmentation.
- Identify patterns associated with customer churn.

## Tools & Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Plotly
- Jupyter Notebook

## Project Structure
- notebooks/: Analysis notebooks
- data/: Cleaned dataset (if redistribution is permitted)
- visualizations/: Exported charts

## Key Findings
- 42.61% of customers belong to the long-term segment.
- 31.04% belong to the new customer segment.
- 26.35% belong to the medium-term segment.
- Churned customers show higher average monthly charges
  across all three tenure groups.
